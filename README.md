# Personal Expense Tracker in C++

## Project Description
Personal Expense Tracker is a beginner-friendly, menu-driven C++ console application that helps users record and manage their daily expenses.

## Features
- Add new expenses.
- View all recorded expenses.
- Calculate total expenses.
- Find the highest expense.
- Exit the application.

## Concepts Used
- C++ variables and data types
- Arrays
- Loops
- If-else statements
- Switch-case
- Functions
- Pass by reference

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program:

   `g++ main.cpp -o tracker`

4. Run the program:

   `.\tracker.exe`

## Storage
The application stores up to 100 expenses in arrays during program execution. Data is not permanently saved.

## Language
C++
